# دليل تشغيل الوكيل بدون خبرة برمجة

## الفكرة العامة
عندك الآن مجلد فيه كل الكود جاهز. الخطوات التالية بتوصلك من "ملفات على جهازك" لـ "وكيل شغال 24 ساعة على الإنترنت".

---

## الخطوة 1: حط الكود على GitHub (مجاني)
1. سوّي حساب على https://github.com (لو ما عندك)
2. اضغط "New repository" واعطيه اسم زي `social-agent`
3. ارفع كل ملفات المجلد يلي عطيتك ياه (فيه زر "uploading an existing file" برفعلك تسحب الملفات وترفعها مباشرة من المتصفح، بدون أوامر)

---

## الخطوة 2: استضف السيرفر مجاناً على Render.com
Render بيشغّل الكود إلك تلقائياً بدون ما تكتب أي أمر:

1. سوّي حساب على https://render.com (فيه ربط مباشر بـ GitHub)
2. اضغط **New +** → **Web Service**
3. اختار الـ repository يلي رفعته على GitHub
4. Render رح يكتشف تلقائياً إنه Node.js، بس تأكد:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. تحت قسم **Environment Variables** ضيف كل المتغيرات يلي بملف `.env.example` (بس بدون كلمة `.example`) وحط فيها التوكنز الحقيقية بعدين
6. اضغط **Create Web Service**

بعد دقيقتين Render رح يعطيك رابط زي:
```
https://social-agent-xxxx.onrender.com
```
هاد الرابط هو الـ "سيرفر" يلي رح تحطه بكل منصة (فيسبوك، واتساب، الخ) كـ webhook URL.

> ملاحظة: الخطة المجانية بـ Render ممكن "تنام" لو ما في زيارات لفترة، وبتاخد كم ثانية تصحى أول رسالة. لو بدك أداء أسرع فيه خطط مدفوعة رخيصة (~7$/شهر).

---

## الخطوة 3: اربط كل منصة بالرابط يلي طلع معك

### فيسبوك + انستقرام
1. روح https://developers.facebook.com → أنشئ تطبيق نوع **Business**
2. ضيف منتج **Webhooks** و **Messenger**
3. بخانة Callback URL حط: `https://your-app.onrender.com/webhook/meta`
4. بخانة Verify Token حط نفس القيمة يلي حطيتها بـ `META_VERIFY_TOKEN`
5. اربط صفحة الفيسبوك وحساب الانستقرام بيزنس

### واتساب
1. من نفس تطبيق Meta، ضيف منتج **WhatsApp**
2. Callback URL: `https://your-app.onrender.com/webhook/whatsapp`
3. Verify Token: نفس قيمة `WHATSAPP_VERIFY_TOKEN`

---

## الخطوة 4: جرب
ابعت رسالة تجريبية عبالماسنجر أو واتساب لصفحتك، ولازم يرد عليك الوكيل تلقائياً خلال ثواني.

---

## ملاحظة مهمة عن تيك توك وتقييمات جوجل
هدول الاثنين أصعب من ناحية الموافقات:
- **تيك توك**: بحتاج تقديم طلب "TikTok for Business API" ومراجعة من طرفهم ممكن تاخد أسابيع
- **جوجل ريفيوز**: بحتاج مشروع على Google Cloud + OAuth verification

إذا بدك أضيفلك الكود الخاص فيهم جاهز، قلي وكمل معك، بس الجزء الأصعب رح يكون الحصول على الموافقة من المنصتين نفسهم مش الكود.

---

## إذا احتجت مساعدة بأي خطوة
ارجعلي وقلي بالضبط وين وقفت (مثلاً "وقفت عند رفع الملفات على GitHub" أو "Render عم يعطيني error") وبساعدك خطوة خطوة.
